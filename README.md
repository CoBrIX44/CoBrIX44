## Selected Work

### 🎬 [ReelAlchemy](https://github.com/CoBrIX44/ReelAlchemy)
`Local-First Instagram Reel Automation Pipeline`

A local automated pipeline that discovers and captures Instagram Reels, identifies embedded audio, retrieves song lyrics, generates context-aware captions via local LLMs, and updates existing Reels autonomously.

`n8n` · `Python` · `Node.js` · `Playwright` · `ShazamIO` · `FFmpeg` · `Ollama`

```text
Discover & Capture Reel
          ↓
  Extract Audio (FFmpeg)
          ↓
 Song ID (Instagram Metadata / ShazamIO)
          ↓
 Retrieve Lyric Snippet
          ↓
 Local LLM Captioning (Ollama)
          ↓
 Browser Session Update (Playwright)
```

- **Audio Extraction & Song Identification:** Extracts audio via FFmpeg and queries Instagram metadata, falling back to ShazamIO for acoustic fingerprinting.
- **Local AI Caption Generation:** Retrieves relevant lyrics and generates custom captions and hashtag sets using locally hosted Ollama models.
- **Automated Web Interactions:** Utilizes Playwright with persistent session storage to edit Reel captions directly on the web interface.
- **Private & Local-First:** Keeps media files, authentication cookies, and model inference entirely on local hardware.

[Explore ReelAlchemy Repository →](https://github.com/CoBrIX44/ReelAlchemy)
