## Selected work

### [ReelAlchemy](https://github.com/CoBrIX44/ReelAlchemy)

**Local-first Instagram Reel automation**

A local pipeline that discovers and captures the latest Reel, identifies its music, retrieves lyrics, generates a caption and hashtags, and updates the **existing Reel**.

`n8n` · `Python` · `Node.js` · `Playwright` · `ShazamIO` · `FFmpeg` · `Ollama`

```text
Discover & capture latest Reel
              ↓
Extract audio · FFmpeg
              ↓
Instagram music metadata
  └─ ShazamIO fallback
              ↓
Retrieve lyrics → random snippet
              ↓
Caption + hashtags · local Ollama
              ↓
Update existing caption · Playwright
```

- **Music identification:** uses Instagram metadata first, with ShazamIO as the fallback.
- **Caption generation:** retrieves lyrics, selects a random snippet, and uses a local model to generate captions and hashtags.
- **Browser state:** uses persistent local sessions for discovery, capture, and caption editing.
- **Local execution:** keeps runtime media, session data, and generated files on-device; n8n orchestrates the workflow.

[Explore the repository →](https://github.com/CoBrIX44/ReelAlchemy)
